## 🚀 About The Project

This project reimagines the classic portfolio website by turning it into a living, tactile operating system. Visitors can drag and resize desktop windows, launch apps, interact with a dynamic top status bar, check real-time system battery metrics, and switch between macOS and iOS views depending on their screen size.

### Architecture

An interactive, web-based operating system simulation that presents a developer portfolio through a dual-interface experience—featuring a full **macOS Desktop workspace** for desktop views and an authentic **iOS iPhone simulator** with hardware bezels for mobile screens.

## ✨ Features

- **🎯 Viewport Adaptability:** Full-screen macOS workstation for desktops, and realistic iPhone hardware enclosure for mobiles.
- **🖥️ macOS Desktop Experience:** Draggable, resizable windows, live system clock, interactive widgets, and smooth dock magnification animations.
- **📱 iOS Mobile Experience:** Hardware frame with physical button accents, real-time battery API integration, and an interactive dynamic island.
- **🔐 Boot & Lock Workflows:** Authentic Apple boot screen loader sequence with swipe-to-unlock and passcode interactions.

## 🛠 Getting Started

Follow these instructions to set up the project locally on your machine for development and testing purposes.

### Prerequisites

Ensure you have the following installed on your local machine:
* [Node.js](https://nodejs.org/) (v16.x or later)
* [npm](https://www.npmjs.com/) (v8.x or later) or [Yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**
   ```sh
   git clone https://github.com/aditya0563/ios-portfolio.git
   cd ios-portfolio
   ```

2. **Install Dependencies**
   ```sh
   npm install
   ```

3. **Run Development Server**
   ```sh
   npm run dev
   ```

4. **Build for Production**
   ```sh
   npm run build
   ```

## 💡 Usage

Once the application is running:
1. Navigate to `http://localhost:5173` (or your configured frontend port).
2. Interact with the desktop interface, open apps, check widgets, and switch to mobile view for the iOS simulator experience.
